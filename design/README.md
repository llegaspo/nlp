# UI image reference

`embedding-workspace-concept.png` was created with the built-in image generation tool before rebuilding the app in React. It guided the compact course navigation, midnight palette, primary embedding plot, right-side prediction inspector, and training flow. The rendered image contains illustrative labels and values; they are not used as lesson data or output.

## Generation prompt

> Use case: ui-mockup  
> Asset type: high-fidelity desktop web app design reference for an interactive NLP lesson site  
> Primary request: Create one polished 16:10 desktop screenshot mockup for “NLP Visual Lab”, a learning workspace about natural language processing. The first visible lesson is “How embeddings form”. Show a compact left sidebar with 8 numbered lesson topics, a central live-looking 2D embedding plot with labeled word points and axes, a training flow from context words to vector to predicted word, a right inspector with current softmax probabilities and loss, and clear controls for CBOW / Skip-gram and Train one step. The information hierarchy must put the interactive experiment first, with no marketing hero. Use a coherent midnight ink/navy foundation, vivid mint/cyan for active data, restrained amber for comparison, crisp white text, legible typography, generous spacing, rounded but precise panels. Style should feel like a premium scientific instrument crossed with a modern digital textbook, visually distinctive and feasible to implement in React/CSS. The embedding plot should read as a real data visualization, not particle art.  
> Composition/framing: full browser viewport, straight-on interface screenshot, useful at desktop width, clear panel boundaries and navigation.  
> Text (verbatim, if legible): “NLP Visual Lab”, “Learning embeddings”, “Skip-gram”, “CBOW”, “Train one step”, “Current loss”.  
> Constraints: No people, no photos, no irrelevant illustrations, no fake code editor, no oversized hero, no decorative charts in place of the requested experiment. Do not show a browser frame, watermark, or multiple screens.
