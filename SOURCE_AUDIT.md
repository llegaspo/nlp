# Source and calculation notes

The app uses the twelve PDFs in `../.docs`. These conventions make the interactive calculations reproducible.

- **Tokens:** Word tokens use Unicode letters and numbers with internal apostrophes. The token lab can case fold, retain punctuation, or use Unicode NFKC. Its BPE demonstration starts from characters inside words, counts adjacent pairs across all occurrences, and omits the end-of-word symbol and deployment refinements of the [Sennrich et al. BPE paper](https://aclanthology.org/P16-1162.pdf). It is labeled as a teaching implementation.
- **Edit distance:** Rows represent prefixes of the source; columns represent prefixes of the target. Insertion, deletion, and substitution have editable nonnegative costs; a match costs zero. The default `STRENGTH → TREND` distance is 4 with unit costs and 5 when substitution costs 2, as in `[2a] Edit Distance.pdf`, p. 6.
- **Context vectors:** A context occurrence contributes one count for every neighbor within the selected radius on each side. The target–context matrix is directional. Cosine is undefined for a zero vector.
- **Embeddings:** The trainer uses two dimensional input embeddings, separate output weights, and full softmax. CBOW averages context embeddings; skip-gram predicts each neighbor from the center word. The slide `[2b] Word Embedding.pdf`, p. 15 describes a nonlinear CBOW hidden transformation, while the [original Word2Vec paper](https://arxiv.org/abs/1301.3781), §3.1 describes a log-linear CBOW with the nonlinear hidden layer removed. The app explicitly follows and cites the original architecture.
- **N-grams:** The four cat-and-dog training sentences are from `[3a] ngram language modelling.pdf`, pp. 20–24. Each sentence receives start padding and a predicted `</s>` token. `<s>` is not a predicted vocabulary item. Thus `C(the, cat)=3`, `C(the)=8`, and `P(cat | the)=3/8`.
- **Perplexity:** Calculations use unrounded conditional probabilities and include `</s>` in the number of predictions. `[3b] Evaluating Language Models.pdf`, p. 5 rounds intermediate probabilities (`3/8` to `0.37`, for example), so its displayed final value differs from an exact recomputation. Scores are comparable only with identical test text and tokenization. This is consistent with [Jurafsky and Martin, chapter 3](https://web.stanford.edu/~jurafsky/slp3/3.pdf).
- **Smoothing:** Add-one and add-k distributions use the same predicted vocabulary as MLE. The interpolation example uses the weights from `Exercise 3.pdf` and renormalizes over available context orders if a selected history has no counts. Stupid backoff is shown only as a score because it is not a probability distribution, as stated by `[Notes] Interpolation and Backoff.pdf` and [Jurafsky and Martin, chapter 3](https://web.stanford.edu/~jurafsky/slp3/3.pdf). Good–Turing is a separate editable frequency spectrum; ratios needing absent `N_c` values remain undefined.
- **Neural network:** A consistent 2-input, 2-hidden, 2-output demonstration is used. The dimensions on `[4a] Neural Networks for NLP.pdf`, p. 14 appear inconsistent: the shown input example has three values while the shown weight matrix has four input columns. The app does not reproduce those particular numbers.

The course introduction (`[1a] Introduction to NLP.pdf`, pp. 6–9) restricts use of generative AI for submitted assignments. The app includes original prediction prompts and does not provide completed submissions for `exercise1 tokenization.pdf` or `Exercise 3.pdf`.
